# Papers Library — Index

Central library of paper / article notes for the playground. Every note follows the
`/read-to-learn` paper template (core claim · methodology · evidence standard ·
mechanism · implementation reality · connection-to-platform · 1–5 scoring).

**Convention:** one canonical note per paper, named `paper_notes_<author><year>.md` (or
`paper_notes_<author>_<topic>_<year>.md`). A paper that surfaced while reading several
books gets **one** merged note here; the per-book connection tables are preserved inside it,
and each book's `reading_queue.md` links back to this folder.

New standalone paper reads (not tied to a book) land here directly.
